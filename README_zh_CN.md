# Analog Canvas 思源插件

[English](./README.md)

在思源笔记里绘制专业模拟电路原理图。插件内置开源
[Analog Canvas](https://github.com/cascode-ai/analog-canvas) 编辑器，完全离线
可用，不需要注册账号，电路文件直接保存在思源工作空间里。

![Analog Canvas 嵌入思源](./preview.png)

## 功能

- **画完直接插入为普通图片**：默认 PNG，可选 SVG；图片就像思源里的普通图片，
  是笔记正文的一部分。
- **源文件仍可编辑**：每张图片对应一个
  `assets/analog-canvas/*.icproj.json` 源文件。右键图片 →「编辑电路图」即可
  重新打开。
- **一键插入**：编辑器里点击浮动按钮「插入到笔记」；插件会先保存源文件，再
  导出图片，并插入到输入 `/ac` 的那个块后面。
- **完整编辑器标签页**：器件库、层次化 Cell、连线、标签、属性和网表编辑。
- **常用电路模板**：新建时可选空白、共源放大器、电流镜负载差分对、两级运放、
  五管 OTA（Sky130）作为起点，创建后仍可自由修改。
- **自动保存与版本快照**：编辑器打开时每 15 秒自动保存；每次保存前的旧版本
  存入 `assets/analog-canvas/.history`，默认保留最近 20 份。右键电路 →
  「历史版本」可查看、恢复或另存为副本。
- **关闭保护**：有未保存更改时，关闭编辑器标签、按 Ctrl/Cmd+W 或退出思源
  都会先询问「保存并关闭 / 不保存关闭 / 取消」。
- **Ctrl/Cmd+S 直接保存**到 `assets/analog-canvas` 下的 `.icproj.json`。
- **导出 SVG / PNG / SPICE / Spectre**：通过编辑器「File → Export」
  打开系统保存对话框，可自由选择保存位置；在插件设置里可以指定默认导出
  文件夹。PNG 支持 1×–6× 导出倍率（默认 3×），适合打印和放大查看。
- **复制到剪贴板**：右键笔记里的电路图片可复制 PNG 或 SVG；编辑器浮动按钮
  也提供「复制 PNG / 复制 SVG」，不需要先保存成文件。
- **电路管理**：选择器的「⋯」菜单和左侧电路面板支持打开、复制、重命名、
  删除和历史版本。
- **在线图库侧边栏**：从右侧栏图库图标或设置页打开可调整宽度的在线图库
  侧边栏。首次使用请在思源内登录窗口完成登录（邮箱验证码、GitHub 或
  Google），登录后浏览社区电路；在在线画布上复制电路，回到本地编辑器点
  「插入电路」即可放到当前图纸上。浏览器中的登录状态与思源不共享。
- **入口可开关**：设置页可隐藏顶栏的「打开 Analog Canvas」按钮和侧边栏的
  在线图库图标，保持边框简洁。
- **导入工程**：从选择器或在线图库侧边栏把在线编辑器导出的
  `.icproj.json` 导入到 `assets/analog-canvas`。
- **可选交互预览**：设置里可切换为插入交互式预览块（预览页只加载已导出的
  图片，不再额外运行一整套渲染器，内存占用更低）。
- **基于 assets 存储**：电路和图片随思源同步、导出和备份一起走。

## 环境要求

- 思源笔记 **3.1.0** 或更高版本。
- 插件内置编辑器约 **8 MB**（安装包约 3 MB，已移除 PDF 导出和 RNL 运行时）。
- 推荐桌面端；移动端可正常预览，完整编辑器会以全屏对话框打开，但较重。

## 使用方式

1. 安装并启用插件。
2. 在笔记中输入 `/ac`（或「插入电路图」），点击「新建」选择模板或已有文件。
3. 在编辑器标签页里画图。完成后点击浮动的 **「插入到笔记」** 按钮（默认
   PNG）；插件会保存源文件、导出图片，并把它插入到输入 `/ac` 的那个块后面。
   也可以点「复制 PNG / 复制 SVG」直接放进剪贴板。如果你只想把图导出成
   文件，使用 **File → Export → Drawing as PNG/SVG**，插件会弹出系统保存
   对话框，由你选择保存位置；设置里可调整 PNG 导出倍率（1×–6×）。
4. 右键插入的图片 →「编辑电路图」可再次编辑；改完后点浮动的
   **「更新笔记图片」**，源 `.icproj.json` 和笔记里的图片都会同步更新。
   右键图片还可复制 PNG/SVG 或查看 **「历史版本」**。
   在 **设置 → 默认导出目录** 可以指定导出对话框默认打开的文件夹；
   留空则使用系统上次的位置。
5. 选择器里的 **「⋯」** 菜单可管理电路（打开、复制、重命名、删除、历史版本）；
   左侧电路面板也有同样的操作。
6. 想借用社区电路时，从右侧栏图库图标、选择器、电路面板或
   **设置 → 在线图库** 打开 **「在线图库」**，它会以可调整宽度的侧边栏出现。
   先点 **「思源内登录」** 完成一次登录（支持邮箱验证码、GitHub、Google），
   然后在图库里打开一个电路，在其画布上按 `Ctrl/Cmd+A` 全选、`Ctrl/Cmd+C`
   复制。回到电路编辑器，点 **「插入电路」**（或按 `Ctrl/Cmd+Shift+V`），
   再点击画布放置。只插入图纸内容，目标工程本身的名称和身份不变。
7. 如果嵌入的侧边栏无法复制，可用 **「浏览器打开」** 在普通浏览器里访问
   图库；也可以在那里用 **File → Export → Project File…** 导出工程，再回到
   选择器点 **「导入」**。

顶部按钮、左侧电路面板和命令面板（`Open Analog Canvas`，macOS
`Alt+Cmd+A`）可以打开资源选择器；从这些入口打开已有工程不会自动插入，
需要插入时请在笔记里用 `/ac`。

在线图库是托管服务，不属于离线编辑器包的一部分；使用它需要联网并登录
图库账号，其中的电路仍受各自作者条款约束。

## 存储与迁移

```text
<工作空间>/data/assets/analog-canvas/
├── five-transistor-ota-20261023123000-ab12cde.icproj.json   # 源文件
├── five-transistor-ota-20261023123000-ab12cde.png            # 插入的图片
├── .history/                                                 # 版本快照（不参与电路列表）
│   └── five-transistor-ota-....20261024153000-ab12cde.icproj.json
└── ...
```

电路和图片都是普通思源 assets，会随工作空间导出、同步和备份。图片块用
`custom-data-assets` 记录源文件路径，用 `custom-ac-image-path` 记录图片路径。

> 如果笔记已经引用某个 `.icproj.json`，请勿在思源之外重命名或移动它；用
> 插件里的重命名操作会自动更新引用。

## 内置内容说明

- 编辑器来自上游 Analog Canvas 的**离线桌面组合**，固定在 commit
  `729cfb1ed7e01f3ba5e56bd1aca41ae03731aab4`。
- 上游源码只做**构建期最小改动**：支持 SiYuan 的 PNG 导出倍率、移除 PDF
  导出与 RNL WebAssembly 运行时、关闭 modulePreload。所有改动都写在
  `scripts/build-editor.mjs` 中，插件再注入一层很小的宿主 shim，把编辑器的
  `/desktop/*` 文件桥接映射到思源插件。
- 内置模板来自上游自带的示例工程（AGPL-3.0-only）。
- 不包含云端功能（账号、Cloud Projects、社区 Gallery、Agent、托管仿真）的
  离线实现；「在线图库」侧边栏只是链接到托管服务，插入电路走系统剪贴板。
- 不包含 PDF 导出和 RNL 格式；SVG/PNG、SPICE/Spectre 网表导出仍可离线使用。
- 暂未启用本地用户元件库。

## 从源码构建

需要 Node.js 24+、Corepack 提供的 pnpm、Git。

```bash
pnpm install
pnpm build          # 构建插件和精简版编辑器包
pnpm package        # 生成 package.zip
pnpm make-link      # 把 dist/ 链接到思源工作空间（可用 --force）
```

`pnpm build` 会从 GitHub 拉取固定的上游 commit（失败时尝试镜像），应用
`scripts/build-editor.mjs` 里的构建期补丁并构建。只改插件代码、想复用已有
编辑器产物时，可设置 `AC_SKIP_EDITOR_BUILD=1`。

## 已知限制

- 内置编辑器界面是英文的；插件自身的对话框支持中英文。
- 不包含 Cloud Projects、社区 Gallery、Agent、托管仿真、本地用户元件库、
  PDF 导出和 RNL 格式。「在线图库」侧边栏是可选在线功能；本地 SVG/PNG
  出图、SPICE/Spectre 网表导出、层次化设计均可离线使用。
- 在线图库需要登录和联网。浏览器和思源使用独立的 cookie 存储，浏览器里的
  登录状态不会自动带入侧边栏，请在侧边栏点 **「思源内登录」** 完成一次登录。
  由于它是跨域页面，电路通过系统剪贴板传递，不是直接拖拽；如果侧边栏里复制
  受限，请用浏览器打开图库，再用工程文件导入作为回退。
- 建议一个编辑器标签页只放一个电路。编辑器内部可以再开多个工程标签，但
  思源标签页的标题和导出元数据只跟踪最初打开的工程。
- 更新图片后，已经打开的笔记可能仍显示缓存的旧图；重新打开笔记即可。
- 电路正在编辑器里打开时不允许重命名或恢复历史版本，请先关闭编辑器。
  重命名会一并迁移版本快照并更新图片引用；如果之前插入过可选的交互预览块，
  需要重新插入。
- 自动保存每 15 秒运行一次；关闭标签时仍会检查未保存的改动。若你正在编辑
  文字，自动保存会跳过，直到输入结束。
- 默认插入静态图片；设置里可以切换成交互预览。
- 原生「另存为」对话框仅在桌面端可用；浏览器/移动端会回退为浏览器的
  保存/下载流程。
- 移动端可用，但完整编辑器较重；推荐桌面端。
